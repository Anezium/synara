## Spec consistency notes

Two spec lines conflict with the current tree state. Both are doc findings, not
code findings.

1. Acceptance criterion 7 says no "menu, or window frame tool is reachable by an
   agent." The 2026-09-17 audit update made `computer_invoke_menu` and
   `computer_set_window_frame` agent-facing under approval (`capability-audit-2026-09-16.md`
   "2026-09-17 update"; `computerTools.ts:142`–`:143`). The criterion text is
   stale; raw session and raw recording remain correctly excluded.
2. Acceptance criterion 6 expects the protocol file to document `cancel_input`,
   the ack fields, and the refusal taxonomy. `cuaDriverProtocol.ts` documents
   the transport, effect taxonomy, and allowlists but not `cancel_input` or the
   cleanup acknowledgement; those live in `cuaDriverHost.ts:805` and the patch
   notes. The spec text or the file must change before an auditor passes that row.
